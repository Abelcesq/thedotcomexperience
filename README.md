# The Dot Com Experience

> **Discover · Live · Manifest — Experience the Experience.**

A movement-in-formation: a modern philosophy of human purpose and existence, paired with
concrete, actionable methods that produce real, meaningful life results — and oriented
toward **stewardship**: responsible, visionary care for one another and for all of life.

This repository is the **container** — the operating system for building the movement
*before* content, marketing, and promotion begin. It holds the project's purpose, its
virtual board of advisors, its skills, and its day-to-day command center.

## The three-part framework

| Folder | Purpose |
| --- | --- |
| [`knowledge/`](knowledge/) | Who the CEO is, why each project exists, the brand voice, and the Virtual Board of Directors. |
| [`skills/`](skills/SKILLS.md) | The registry of repeatable capabilities (implemented in `.claude/skills/`). |
| [`projects/`](projects/) | Each project, with a `PROJECT.md` and a live dashboard. |

## Governance in one line

The **CEO (Abel)** decides. The **Virtual Board** advises (as guardrails, in their own
voices). **Claude** is the project manager — decomposes, drafts, audits, and recommends,
without sugar-coating.
