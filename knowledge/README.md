# knowledge/

Everything an agent must understand **before acting**. If context is missing, the answer
is here — or it needs to be added here.

| Subfolder | What it holds |
| --- | --- |
| [`about-me/`](about-me/) | The CEO — values, strengths, working style, constraints. |
| [`project-purpose/`](project-purpose/) | The purpose and intention behind each project. |
| [`brand/`](brand/) | The voice, themes, and language of the movement. |
| [`board-of-directors/`](board-of-directors/) | One profile per virtual advisor + how the board operates. |

**Rule:** Knowledge files are the source of truth for *context*. Keep them current. The
`continuously-improve` skill reads every MD file here at the start of each audit to rebuild
context before assessing anything.
