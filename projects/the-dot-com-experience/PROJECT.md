# PROJECT — The Dot Com Experience

> The canonical "what this project is" file. A future portfolio-level manager should be able
> to read this and understand the project in three minutes.

## One-liner
A modern-philosophy movement — *Discover, Live, Manifest* — that teaches human purpose and
gives people concrete methods to create meaningful results, monetized through a premium,
Disney-grade merchandising/IP brand, and oriented toward stewardship of one another and all life.

## Type
Movement + media/IP brand (philosophy-led, merchandising-monetized). Pre-launch.

## Owner
CEO: Abel. PM: Claude. Advisors: the Virtual Board of Directors.

## The four corners (see `clarity.md` for detail)
- **Purpose:** explain human purpose/existence and make it *actionable*.
- **Current state:** content archive + X presence + explainer video; **container being built
  now** (this repo). No product, funnel, or revenue yet.
- **End goal (aspirational):** a globally recognized modern philosophy + premium brand.
- **Realistic near-term goal:** a coherent container, a defined first offer/audience, and a
  consistent content engine that earns its first true believers.
