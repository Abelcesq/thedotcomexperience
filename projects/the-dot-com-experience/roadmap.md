# Roadmap — Container → Content → Platform → Brand

Phased so that **audience and resonance precede product and platform.** Each phase has an exit
test; do not advance until it's met. Maps directly to the CEO's 8-step plan (step numbers noted).

> Legend: ✅ done · 🟡 in progress · ⬜ not started · 🔮 aspirational (needs CEO decision + budget)

---

## Phase 0 — Build the container  *(Steps 1–4, 7–8)*  ✅ (this work)
Establish governance, context, board, skills, and the operating system.
- ✅ Container structure (knowledge · skills · projects)
- ✅ Top-level `CLAUDE.md` (project-manager / chain of command)
- ✅ Clarity doc (purpose / state / end goal / realism)
- ✅ Virtual Board of Directors (9 profiles) + consult skill
- ✅ `continuously-improve` audit skill
- ✅ Command-center design + dashboard
- ✅ AI-discoverability assets (`llms.txt`, `web/robots.txt`)
- **Exit test:** CEO has reviewed and answered the open questions in `clarity.md`. ⬜

## Phase 1 — Define the wedge  *(Step 1 deepened)*  ⬜  ← **next**
Turn vision into a sharp, testable starting point.
- ⬜ Name the **first audience** and the exact pain (CEO input required).
- ⬜ Make the **Discover·Live·Manifest** method *concrete*: a simple, repeatable framework
  (steps, practices, a name) someone could actually follow this week.
- ⬜ Define the **first free offer** (the lead magnet / signature framework) and the **first
  paid offer hypothesis** (could be a small product or merch drop — to be validated, not built).
- **Exit test:** One sentence each for audience, pain, free offer, and the transformation —
  all approved by the CEO.

## Phase 2 — Prove the voice (content engine)  🟡-able now
Show the philosophy resonates *before* investing in platform/merch.
- ⬜ Pick 1–2 channels (X is already live) and a **sustainable cadence**.
- ⬜ Repurpose the existing archive; build a 2–4 week content bank in-voice.
- ⬜ Stand up **one simple owned home**: a landing page that captures emails (so the audience
  is yours, not rented from an algorithm).
- ⬜ (Future skill) `content-engine` to scale on-voice production.
- **Exit test:** Consistent posting for 4+ weeks and a first cohort of genuinely engaged
  followers + a growing email list. Resonance is demonstrated, not assumed.

## Phase 3 — Owned platform & always-on systems  *(Steps 5–6)*  🔮
Only after Phase 2 shows demand worth supporting.
- 🔮 Website + domain; AI-discoverable by design (semantic HTML, meta descriptions,
  `llms.txt`, `robots.txt` at web root — assets drafted in `web/`).
- 🔮 Hosted platform so agents/skills/data run **independent of a local drive** (e.g., the
  repo in cloud git + a hosting provider; automation via scheduled jobs).
- 🔮 **Security**: secrets in a manager (never in the repo), least-privilege access, 2FA,
  dependency scanning, backups. (Baseline already enforced via `.gitignore`.)
- **Exit test:** The movement has a real home and runs without depending on one machine.

## Phase 4 — Productize & monetize (the merch/IP brand)  *(business model)*  🔮
- 🔮 Brand system (visual identity, motifs: seed/tree, the Dot, Discover·Live·Manifest).
- 🔮 First merchandise drop / product to a warm audience.
- 🔮 IP & legal: trademark, entity, content licensing posture.
- **Exit test:** First revenue from a premium product an existing audience *wants*.

## Phase 5 — Scale toward the North Star  🔮
- 🔮 Programs/experiences, partnerships, deeper IP (books, courses, licensed goods).
- 🔮 Codify the philosophy into a durable, teachable body of work.
- **Exit test:** Self-sustaining brand with compounding reputation and IP — the Munger "moat."

---

## Sequencing principle (why this order)
Hormozi & Munger agree on the failure mode to avoid: **building product/platform before
demand.** Proverbs: *"the plans of the diligent lead surely to abundance"* — but plans, not
leaps. We validate cheaply (content, list) before we spend (platform, merch). The board will
be consulted at each phase boundary via the `board-of-directors` skill, and **the CEO approves
each advance.**
